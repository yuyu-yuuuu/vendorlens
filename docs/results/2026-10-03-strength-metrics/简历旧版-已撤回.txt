定位
AI 应用工程 / 后端开发方向，具备证据驱动 Agent、混合检索、确定性业务核验、异步任务恢复和可复现评测的项目实践。

项目经历
VendorLens 证据驱动供应商评审平台
技术栈：Python / FastAPI / LangGraph / SQLAlchemy / PostgreSQL / Redis / RQ / ChromaDB / Docker / Next.js / TypeScript
项目背景：面向企业采购方案评审，读取需求书、供应商方案、报价和排期，围绕需求符合性、总拥有成本与交付承诺生成可回查版本原文的供应商对比报告。

强指标版
- 设计单供应商评审 Agent 与供应商间并行工作流，一次输出需求、成本、承诺 3 个领域结果，结合 11 个受控工具、领域校验、最多 2 次局部返工与确定性降级；自建 52 条合成需求回归样例，四分类 Accuracy 100.00%、Macro-F1 1.00；另运行 5 组真实模型样例，最终需求判断 4/5 正确、14/15 个领域结果可用，保留失败字段供返工诊断。

- 构建父子 Chunk + BM25/ChromaDB + RRF 混合检索，按项目、供应商和最新已索引版本隔离召回，并为报告保存固定版本引用快照；在 192 个合成片段、96 条模板化查询上，Hybrid Recall@3 100.00%、MRR 1.00，项目/供应商/版本过滤泄漏 0/96；以 6 类来源篡改场景验证范围和哈希门禁，12/12 次攻击被拒绝。

- 将成本金额、币种和周期绑定原文片段，使用确定性工具计算一次性、年度/月度费用及 TCO，拒绝含糊金额进入评分；24 条合成费用口径回归样例 24/24 与预设结果一致，5 组真实模型样例 TCO 5/5 与 gold 一致；建立必选需求淘汰、必要费用缺项和条件推荐规则，评分使用公开的 50/30/20 默认权重。

- 实现三层会话记忆和动态 Skills：最近消息、带版本依赖的评审摘要与显式偏好进入任务冻结上下文；20 个会话、320 条消息中，16 条压缩并保留最新 6 条的检查 20/20 通过，实测 Redis TTL 为 24h；50 次规则热更新与 50 次非法配置回退分别 50/50、50/50 通过。

- 构建租约/心跳/Checkpoint 恢复、事务 outbox、SSE 续读与父子 Trace，依据模型耗时、错误和领域校验更新端点健康分；在 20 组模拟故障场景中注入 60 次限流，冷却切备、单探测租约和成功恢复 20/20 通过；建立 237 项后端回归测试，提供实测 JSON、失败样例和测试方法报告。

精简投递版
- 构建证据驱动供应商评审 Agent，覆盖需求、成本、承诺 3 个领域与 11 个受控工具，支持并行分析、2 次局部返工、确定性降级及公开权重推荐；建立 52 条需求、24 条费用口径合成回归样例。
- 实现父子 Chunk、BM25/ChromaDB/RRF 检索与版本固定引用，在 192 个合成片段、96 条模板化查询上验证召回及项目/供应商/版本隔离；6 类来源篡改测试 12/12 被拒绝，5 组真实模型样例 TCO 5/5 与 gold 一致。
- 实现三层记忆、Skills 热加载、健康路由、任务租约恢复、事务 outbox、SSE 与 Trace；50 次热更新/50 次非法配置回退、20 组路由故障注入测试通过，维护 237 项后端回归与可复现测试报告。

面试数据口径
这些数字来自项目内合成回归集、真实模型小样本和受控故障注入。不是生产数据，不宣称 Hybrid 优于 BM25；真实模型存在错误和数字门禁失败。完整方法、分母、逐项结果与各轮模型输出均保存在测试报告及原始产物中。
