## 接口与交互

核心流程通过浏览器操作隔离 SQLite/本地索引项目，使用正式 API、检索、校验、报告事务和 SSE；模型执行器替换为确定性离线实现，队列替换为测试线程。未调用付费模型，未写入现有运行服务的业务数据。

- 合成 Markdown 上传至指定供应商，返回保存成功，列表显示版本 v1 与已索引。
- 保存评审补充意见，创建关联会话的新任务；读取 queued/running、节点完成、部分完成的持久化事件。
- 查看新报告，打开冻结版本原文；原文弹窗展示正确文件与行范围。
- 运行记录展示节点/Agent/检索父子链；未提供 Token 与金额时显示“未提供”。
- Skills 重载、版本/哈希读取及偏好保存成功。
- 示例与真实模式独立；API 错误不会替换成示例报告。

联调修正：配置读取路径改为 review-config；Next 将 URL 规范化为 localhost 时仍按浏览器 Host 校验同源写入；跨站与异常 Origin 仍拒绝。上传失败重载列表后保留错误文本，避免错误被清除。空承诺 findings 不展示为已明确。
