# 后端闭环补齐

本轮用户授权补齐整个后端待办，保留单 VendorReviewAgent、三个领域、证据门禁与现有未提交改动。不涉及前端，不自动提交，不执行付费模型验证。

1. 管理 API：项目与供应商增查改、需求增查改、评审配置读写、资料上传/版本列表/来源读取/显式重新索引、项目任务列表。已有业务对象不硬删除，避免破坏冻结报告。上传受大小/格式/归属约束，解析与索引分阶段提交，索引失败保留可重试的版本。
2. 任务恢复：数据库执行租约与心跳、运行归属 fencing、过期运行恢复及入队失败重试；使用持久化 LangGraph checkpoint 继续，保持原 run_id/trace_id 与冻结输入。节点内的外部模型调用仅保证至少一次，中断节点可能重做；完整 checkpoint 已结束时仅补业务结果提交。
3. 检索运行配置：保持离线哈希默认；可选本地中文 SentenceTransformer 和 CrossEncoder，加载本地模型目录，不自动下载。API 索引和 Worker 查询共用配置与独立集合指纹。BM25 更新加跨进程锁并重新读取，防止并发覆盖。
4. 可观测性：/metrics 从业务库读取低基数 Prometheus 指标；模型费用按照显式配置的输入/输出单价记录估算，只在完整 usage 与两项价格存在时计算，冻结价格并注明币种，未知不当零。
5. 完整性：必要成本类别与承诺检查进入正式结果和降级，避免材料不齐得到无条件推荐。
6. 演示与评测：离线 CLI 从新数据库完成摄取、真实本地索引、隔离检索、评审/降级、结果持久化，输出结构化产物；合成材料不等于生产效果。

测试验证管理接口归属/版本/幂等与失败，租约并发、恢复 checkpoint、重复投递，模型适配配置与排序，费用未知/完整统计、指标输出及离线端到端。迁移在独立测试数据库执行，不覆盖用户已有数据库。学习主线为 RAG、Agent/工具、证据门禁、故障恢复、评测；已实现三层会话记忆、独立 Skills 文件热加载与冻结快照，以及监控驱动的模型端点路由、冷却和探测。实现约束见[会话、Skills 与路由记录](../../learning/2026-10-02-conversation-skills-routing.md)。
